One funny safety warning label that should come printed on every human being — a [make.fun](https://make.fun) bounty entry by [@dizellacapital](https://make.fun/r/qxacafna).

## The line

> WARNING: Contents may spontaneously start a podcast about a hobby picked up yesterday. No off switch included.

A real label format — WARNING header, "Contents may…", a label-style closing clause — wrapped around a very 2026 human habit: picking up a hobby yesterday and already starting a podcast about it. The punchline lands on the last words, like a clause printed in small type at the bottom of the box.

## How it works

`main.py` (stdlib only) writes the line to `MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output`), validates it is one line of 1–160 characters, and verifies the write by reading it back. The entry file is exactly 110 characters, with no trailing newline.

```sh
python3 main.py
```
